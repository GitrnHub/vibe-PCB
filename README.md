# vibe-PCB

AI-assisted open hardware product platform.

## Vision

vibe-PCB is not only a PCB library. It is a complete product engineering workflow:

- Hardware design
- PCB manufacturing
- Firmware
- Mechanical structure
- Product visualization
- AI design history

## Current Product

### vibe-EPD Platform

An ESP32-S3 based universal E-Ink development and product platform.

Features:

- ESP32-S3 controller
- Universal EPD FPC interface
- Low power architecture
- Open PCB manufacturing files
- Modular future expansion

## Repository Structure

```
hardware/       PCB, BOM, Gerber

mechanical/     Enclosure and CAD

```
